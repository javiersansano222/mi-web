03 / DENTRO DEL ORDENADOR

Cada pieza,
una función.

Un ordenador es mucho más que una caja con luces.

Cada pieza cumple una función concreta y todas trabajan en equipo: el procesador ejecuta las órdenes, la memoria RAM guarda lo que se está usando, la tarjeta gráfica dibuja cada imagen, el almacenamiento conserva los datos y la refrigeración mantiene todo a temperatura estable. Pasa el ratón por encima de cada punto para descubrirlas.
